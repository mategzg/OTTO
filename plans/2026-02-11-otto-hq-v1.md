# Plan - OTTO HQ v1 Base

Fecha: 2026-02-11

## Objetivo

Construir base operativa OTTO HQ production-ready v1 con dashboard local, estado/kanban/logs, indices docs y scaffolding de delegacion.

## Alcance

- Estructura de carpetas HQ
- Scripts stdlib: `otto_state.py`, `dashboard_server.py`, `index_docs.py`
- UI dashboard local
- Reglas y docs (ROUTER/HEARTBEAT/README)
- Scripts PowerShell para bootstrap, run, demo
- Tests pytest (>=4)

## Criterios de salida

- Tests en verde
- JSON determinista
- Logs append-only
- API dashboard funcional y segura ante traversal
- Entrega con instrucciones Windows-first

## Riesgos

- Entorno sin Python/pip
- Diferencias de path entre Linux/Windows
- Integraciones Jack/Coder dependientes de sesion/herramienta externa

## Entregables

- Codigo y estructura OTTO HQ v1
- Documentacion de uso e integracion
- Scaffolding de delegacion file-based
