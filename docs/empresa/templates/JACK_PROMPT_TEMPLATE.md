# JACK Prompt Template (SG-only)

Usa esta plantilla para consultas a JACK exclusivamente sobre SG.

```text
Contexto SG:
- Unidad/area: <completar>
- Cliente/proyecto: <completar>
- Objetivo puntual: <completar>

Consulta (SG-only):
<detallar aqui precios, proveedores, criterios SG, politicas SG, o cotizaciones SG>

Formato de salida solicitado:
1) Resumen ejecutivo (max 8 lineas)
2) Recomendacion concreta
3) Riesgos / supuestos
4) Datos faltantes para cerrar decision
```

No incluir datos personales ni temas fuera de SG.
