# Runbook 30s — Dashboard OTTO v1

## Qué mirar primero (15s)
1. Estado OTTO (arriba izquierda)
2. Delegación activa y bloqueos (arriba centro)
3. Siguiente mejor decisión en SG y Personal

## Flujo de uso diario
1. Abrir dashboard
2. Revisar semáforos rojos/ámbar
3. Ejecutar 1 decisión SG + 1 acción Personal
4. Ver actividad para confirmar avance

## Botones clave
- `Actualizar`: refresca estado y métricas.
- `Ver actividad`: abre últimos 5 eventos.
- `Pausar delegación`: frena nuevas delegaciones tras confirmación.
- `Ejecutar con OTTO` / `Hazlo por mí`: dispara acción prioritaria.

## Regla práctica
Si una tarjeta no cambia una decisión hoy, se elimina en v1.1.
