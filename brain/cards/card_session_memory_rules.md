# Card: Reglas de Memoria y Aprendizaje

> Fuente: SESSION_MEMORY.md + docs/empresa/memory.md (legacy, feb-2026)

## Reglas de Memoria (definidas por Topo)

1. **Solo info útil a futuro** — no spam operacional
2. **Post-mortem en errores:** qué pasó + cómo evitar repetirlo
3. **Si se redefine una regla** → actualizar SOUL.md / TOOLS.md
4. **Memoria operativa SG** → formato: fecha, contexto, lección, regla preventiva

## Dónde va cada cosa
- Lecciones diarias → `memory/YYYY-MM-DD.md`
- Lecciones duraderas → `MEMORY.md`
- Reglas de comportamiento → `SOUL.md`
- Config de herramientas → `TOOLS.md`
- Aprendizajes SG → `docs/empresa/memory.md` (cuando se recree)

## Principio
No acumular archivos. Digerir, destilar, afilar. El brain tiene cards; el workspace tiene docs operativos. No duplicar.
