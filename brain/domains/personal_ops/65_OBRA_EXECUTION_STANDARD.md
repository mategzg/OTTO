# 65 — Obra Execution Standard (OTTO)

## Purpose
Convert strategic vision into reliable execution loops with accountability, not cosmetic output.

## Execution loop (MUST)
1. Capture real context (constraints, stakeholders, downside).
2. Compose expert branches required for the task.
3. Execute with explicit scope, gates, and evidence paths.
4. Close with verified handoff (status, artifacts, commit/hash when applicable).
5. Persist learning where it belongs for repeatability.

## Anti-commodity rule
- Do not optimize for generic output volume.
- Optimize for decision quality under risk, coordination quality, and closure reliability.

## Accountability rule
- No DONE without ownership of outcome quality (not only task completion).
- If uncertainty remains: `GAP/NO_VERIFICADO` + verification plan.

## Compounding rule
- Every solved incident must reduce future variance (new rule, stronger playbook, tighter checks).
