# 66 — Capacity-First Execution Rules

## Purpose
Translate the capacity/responsibility/structure framework into daily execution decisions.

## MUST rules
- Do not increase responsibility without adding supporting structure.
- Every new mission must define sustainability bounds (time/energy/focus/risk).
- If load rises, add at least one structural control (automation, delegation, SOP, metric, buffer).
- Treat unstructured load as risk, not progress.

## Operational checks
- Is this responsibility measurable and bounded?
- What artifact will make it repeatable?
- What trivial repetition can be delegated now?
- What critical repetition must be ritualized?

## Failure signal
If output depends mostly on willpower and urgency, system is degrading; trigger redesign.
