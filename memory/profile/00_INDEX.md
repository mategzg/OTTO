# Profile Map — Mateo

Objetivo: capturar **perfil personal ejecutable** (identidad, estilo, límites y patrones), separado de visión estratégica y doctrina operativa.

## Regla de lectura (token-efficient)
1. Leer este índice.
2. Cargar solo las ramas necesarias para la tarea.
3. Si aparece contenido de visión/operación, registrar `TODO` y moverlo fuera de esta rama en ciclo posterior.

## Ramas
- `memory/profile/10_IDENTITY.md` — identidad base, motivadores, rasgos estables.
- `memory/profile/20_OPERATING_STYLE.md` — cómo trabaja y cómo mantiene ritmo.
- `memory/profile/30_EXECUTION_RULES.md` — estándares personales de ejecución/calidad.
- `memory/profile/40_SYSTEM_PREFERENCES.md` — preferencias de interacción con sistemas/herramientas.
- `memory/profile/50_DECISION_PATTERNS.md` — heurísticas personales de decisión.
- `memory/profile/60_COMMUNICATION_CONTRACT.md` — contrato de comunicación esperado.
- `memory/profile/70_COLLABORATION_BOUNDARIES.md` — límites y responsabilidades en colaboración.
- `memory/profile/90_OPEN_QUESTIONS.md` — vacíos de perfil por confirmar.

## Criterio de calidad
Perfil útil = específico, verificable por comportamiento, no redundante y fácil de mantener.
