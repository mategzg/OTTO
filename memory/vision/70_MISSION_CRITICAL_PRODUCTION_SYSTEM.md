# 70 — Mission-Critical Production System Plan (Canon)

## Definitive direction
Target role/business: **Production System Lead (Takt + Last Planner) for mission-critical projects** (data centers, hospitals, labs), then productize into company services.

## Role in one line
Owner of the production system: turn plan into reliable weekly progress by zones/trades, with constraints closed early and variability controlled.

## What this role is NOT
- Not office-only scheduler.
- Not document controller.
- Not meeting chaser.

## Weekly operating core
1. Pull/Phase Planning by deliverables.
2. 6-week Lookahead for constraints.
3. Weekly Work Plan commitments by trade/zone.
4. Daily huddles for micro-adjustments.
5. PPC + reasons log + corrective actions.

## System package to deliver
- Zoning/work packaging + Done/Ready criteria.
- Takt plan (cadence, sequence, buffers, adjustment rules).
- Last Planner operating system (rituals, roles, commitment rules, escalation).
- Constraint management with owners/dates/SLA.
- Executive visual board with trends and recovery plan.

## Authority KPIs (non-negotiable)
- PPC (global + by trade)
- Takt variance by zone
- Constraint cycle time
- Plan reliability (WWP compliance)
- Throughput by zone/hitos per week
- Top reasons for non-compliance (trend)

## Capability stack to master
- Lean core: LPS, Pull, Lookahead, Takt, variability/buffers, PDCA/A3.
- Field planning: critical path basics, recovery planning, capacity vs demand.
- MEP literacy: interfaces, prerequisites, install sequence logic.
- Site ops: safety/logistics/first-time-right basics.
- Operational leadership: commitments, sequencing negotiation, escalation without drama.

## Tool stack
- Production planning: Touchplan/VPlanner/Excel robusto.
- Scheduling ecosystem: Primavera P6 or MSP.
- PM platform: Procore / Autodesk Construction Cloud.
- Coordination: Navisworks (+4D tools when used).
- Data power: Power BI + strong Excel.

## Evolution path
- 0–18 months: own PPC/constraints/WWP in area/zone.
- 18–36 months: full Production System Lead.
- Next: Area Delivery / Program ownership.

## Company productization
- 90-day Production System Deployment.
- Monthly Production Operations retainer.
- 4–8 week Recovery Sprint.
- Core asset: reusable playbook (templates, SOPs, readiness rules, dashboards).

## Acceptance filter for roles/projects
Only accept if ownership exists over PPC/plan reliability/constraints and authority to enforce commitments.

## Trap list (avoid)
- Lean without authority.
- Becoming commodity scheduler.
- No trade access.
- No explicit Ready/Done criteria.
