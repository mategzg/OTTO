2. Load only the branch needed for the current task.

- `30_STRATEGIC_AXES.md` → Where effort is allocated (portfolio of bets).

## Interpretation rule
- **North Star** defines direction.
- **Principles** define boundaries.
- **Axes** define strategy structure.
- **Metrics** define evidence.
- **Horizons** define sequencing.
- **Rubric** defines per-decision gating.

No personal profile logic belongs here; this map is shared and system-level.
